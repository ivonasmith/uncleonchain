# 分析报告怎么发布

`/reports/` 板块放周度节奏的深度报告：针对一个方向或议题做全方位分析，给出可以当决策依据的结论。
网站是 Cloudflare Pages 静态托管，**不需要服务器**：报告文件提交进这个目录，推送后 Actions 自动重建网站上线。
报告写入后不改，后续修正另起一篇。

## 工作流（2026-10-04 定）

1. 大叔照常排好**浅色版 HTML**（现在这套暖白纸样式：卡片、表格、SVG 图表都行），中文一份，英文有就再给一份。
2. Claude 放进来：`<日期>-<英文短名>.html`（中文）+ `<日期>-<英文短名>.en.html`（英文，可选，后补也行）。
3. **深色版不用做**：出网站时自动生成 `raw-dark.html`——每个颜色明度翻转、色相保留，覆盖 `<style>`、内联 style、SVG 的
   fill / stroke，任何排版都能适配。读者点太阳 / 月亮，报告跟着切换。图片（PNG / JPG）只压暗一点，不反色。
4. 报告页**不再单独放摘要框**，面包屑下面直接是报告本体（报告开头自己写过重点）。
5. 只有纯文字、没有图表的短文可以直接给文字，Claude 用同一套样式排版；图表多的报告请给排好的 HTML（图背后的数据在研究环境里）。

## 文件放法（按扩展名自动识别）

- **整篇 HTML（推荐）**：`content/reports/2026-10-04-macro-vs-bitcoin.html`，英文版同名加 `.en.html`。
  报告原样放进页面里的 iframe，自己的样式不和站点互相干扰；读者可以点「在新窗口全屏阅读」。
- **带图片的文件夹**：`content/reports/<slug>/index.html`（英文 `index.en.html`）+ 同目录图片等附件。
- **Markdown**：`content/reports/<slug>.md`，头部写元信息（同 content/posts），正文套站点排版。

## 元信息（只给列表页卡片用）

写在 `<head>` 里的注释，英文文件里写英文：

```html
<!--meta
标题: 宏观到底管不管比特币？
日期: 2026-10-04
摘要: 用 16 年数据逐条检验常见说法：宏观管节奏和风险，不管方向。
标签: 宏观, L1, 周末特辑
-->
```

- 文件名决定网址：`2026-10-04-macro-vs-bitcoin.html` → `/reports/2026-10-04-macro-vs-bitcoin/`，英文站 `/en/reports/…/`。
- 英文版缺的时候，英文站显示中文原文，列表卡片标「中文」。
- 报告里的旧推特 ID 统一换成 `@Uncle_Onchain`；`[网站链接]` 这类占位符换成真实链接。
