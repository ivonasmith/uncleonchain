# 大叔点评（人工解读，可选）

每天的解读日志是规则自动写的（`pipeline/写日志.py`，规则见网站「口径与规则」页），写入即冻结。
想在某一天 / 某一周 / 某个月加自己的判断，在这个目录放一个同名 Markdown 文件就行，下次跑网站时会
以「大叔点评」单独显示在对应页面上，和自动解读分开，随时可以改：

- `2026-09-29.md`   → /journal/2026-09-29/ 当日点评
- `2026-W40.md`     → /journal/week/2026-W40/ 周复盘点评（ISO 周，周一到周日）
- `2026-09.md`      → /journal/month/2026-09/ 月复盘点评

正文支持基本 Markdown（# 标题、**粗体**、- 列表、> 引用、[链接](url)），开头的 `---` 元信息可有可无。
推到 GitHub 后 Actions 会自动重跑一次网站，一两分钟后上线。
