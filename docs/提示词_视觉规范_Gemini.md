## 1. 给 Gemini 的提示词

你是一名做数据产品的资深 UI / 交互设计师。请为「链上大叔研究台」（uncleonchain.com）出一套**视觉与交互规范 v1**。

### 产品背景

- 个人 web3 链上数据情报终端，中英双语（英文挂 /en/），深色为主、有浅色主题。
- 读者是交易者和推特读者：多从推文直链进某个板块，**要在 5 秒内看懂「现在是什么状态」**。
- **四个核心板块**：
  1. 宏观仪表盘：BTC 四层周期框架 + 涨跌腿
  2. 发射台：链上新币发行平台热度
  3. 龙头选币：成熟大币的基本面和资金；之后会加 SOL / ETH / NEAR / ENA 等单币深度页
  4. Alpha 雷达：新协议 / 新机会的看板和研究卡
- 其它页面是支撑层：事件日历、AI Agent、RWA、报告、解读日志、口径与规则。

### 内容表达规则（必须体现在版式里）

每个板块按三档组织：

1. **状态**：第一句，大白话。例：「BTC 现在离本轮最低收盘 7 天，还差 +8.2% 才算涨腿确认。」
2. **条件 + 历史**：必须带分母和检验等级。例：「15 次里 8 次……等级：描述统计」。
3. **方法与明细**：可以折叠。

**不允许出现买卖指令**（加仓、止损、抄底等）。检验等级要有统一的标签样式：已验证 / 描述统计 / 假设 / 已证伪。

### 现状（要改进，不是要照抄）

- **颜色**：底 #05070c、卡片 #0b0e17、细线 rgba(255,255,255,.06)、正文 #e8ecf3、次要 #a7afc0、弱 #7f889c、涨 #00ffcc、跌 #ff3366、警示 #ffb020、冷色 #5b8cff、品牌青柠 #a3e635（只用于导航和按钮）。
- **浅色主题**：底 #f5f7fa、涨 #059669、跌 #e11d48。
- **字体**：系统无衬线；数字用等宽、等宽数字（tabular-nums）。
- **结构**：左侧常驻导航；子页面有面包屑；卡片网格。
- **问题**：
  - 信息密度不均：宏观页很密，有的页很空。
  - 各板块组件各写各的：表格、读数卡、图表样式不统一。
  - 首屏重点不突出。
  - 手机端表格靠横向滚动。

### 请交付（Markdown 规范文档 + 一个单文件 HTML 样式示例页）

1. **设计原则**：3–5 条。
2. **Design tokens**：
   - 颜色（深 / 浅两套；语义色：涨 / 跌 / 中性 / 警示 / 等级标签）
   - 字号阶梯、行高、间距阶梯、圆角、阴影 / 边线
   - 断点（桌面 / 平板 / 手机 390px）
3. **版式模板**：
   - 核心板块首页模板：首屏状态区 → 关键读数 → 条件与历史 → 明细 / 方法
   - 单币 / 单协议详情页模板
   - 支撑层列表页模板
4. **组件规范**（每个给状态、尺寸、深浅两版、手机版）：
   - 状态句块、读数卡（大 / 小）、检验等级标签、「条件 + 历史」块（分母怎么排）
   - 数据表（手机端怎么处理）、折叠区、页签、导航与面包屑
   - 空状态 /「待接入」/ 数据过期提示
5. **图表规范**：
   - 走势线、分布（点 + 须）、刻度条 / 分位条、柱状
   - 配色顺序、坐标轴、悬停提示、图例、深浅主题、色弱可读
6. **交互规范**：
   - 加载顺序：静态数字先出，脚本只负责刷新
   - 悬停解释术语、链接与锚点、移动端手势、中英切换后的位置保持
7. **四个核心板块首页的高保真稿**：桌面 + 手机各一张，可用 HTML 或图片。

### 约束

- 只用 CSS 变量，不写死颜色。
- 不引入新字体文件（或只用 Google Fonts 一款）。
- 不依赖框架；页面是 Python 生成的静态 HTML + 少量原生 JS。
- 中英文同一版式，英文更长时不能撑破。
- 涨跌色语义固定：涨 = 青绿，跌 = 红，不能反过来。

## 2. 给 Grok 的调研任务（先做，交给 Gemini）

调研 6–8 个同类数据产品的版面和交互，例如 Glassnode、CryptoQuant、Artemis、Token Terminal、DefiLlama、Messari、Dune 看板、TradingView 指标页。每个产品回答：

1. 首屏怎么让人 5 秒内看懂「现在怎样」？
2. 读数卡、表格、图表的样式有什么可借鉴的？
3. 手机端怎么处理宽表格和图表？
4. X 上用户对它的版面 / 交互有什么抱怨或称赞？要附原帖链接。

**交付**：`docs/视觉规范/竞品调研_grok.md`，每条结论带截图链接或原帖链接，不写没有出处的说法。
