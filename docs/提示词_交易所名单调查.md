```
你在 GitHub 仓库 ivonasmith/uncleonchain 协作（链上大叔研究台）。开工前先读根目录 AGENTS.md（分工、提交方式、数据规矩）和 docs/协作记录.md 最后 10 行。

== 背景 ==
Alpha 雷达把「交易所新上的币」当来源之一，并统计各所上线后价格怎么走。大叔的要求：来源名单**不限数量，按质量筛**，
不是凭感觉定。请对全球前几十名的交易所做一次全面调查，给出事实，供 Claude 按准入标准决定名单。你只给事实，不给「该不该收」的结论。
已确定去掉 MEXC（上币太多、几乎全是噪音）；已在跑 Binance、OKX、Bitget、Kraken；官网被拦、走官方 X 的：Bybit、Coinbase、Upbit、Bithumb、Gate；候选：KuCoin、HTX。这些也要一并给事实。

== 任务 X6：交易所全景表 → alpha/review/x6_exchange_universe.json ==
范围：按 CoinGecko 交易所页的现货 24 小时成交额取前 50 名，再补 5 家没进前 50 但上币有影响力的（有就写，没有不凑）。只收中心化交易所；去中心化交易所（DEX）另放在 `dex` 数组里，只给名字和链，不展开。
每家一条，字段（拿不到写 "U"，不估不编；每条带来源链接和核对日期 UTC）：
- name、官网、成立年份、注册地 / 主要监管主体（官方说法，附链接）
- rank_source：CoinGecko 排名、24 小时现货成交额（美元）、trust_score、取数日期和链接。不要用 CoinMarketCap 的 data-api（项目安全规则不允许），可以引用 CoinMarketCap 网页但要标二手
- listing_activity：近 12 个月新币现货上线数量（给统计方法和来源；没有就写 U，别拿公告数硬凑）；其中代币化股票 / ETF、跟单、理财 / 活动类公告占「上币」类公告的大致比例（抽查最近 30 条公告，写出你数的结果）
- announce_source：官方公告页、可读接口（REST / RSS / WebSocket）、官方 X 账号（用户名 + 是否真的发上币帖）、从美国数据中心（GitHub Actions）能否访问（HTTP 状态，实测写 200 / 403 等，没测写 U）
- listing_info：公告里是否写计划开盘时间、交易对；是否有预热 / 集合竞价 / 盘前合约；是否有空投 / Launchpool 类活动
- kline：官方公开现货 1 分钟 K 线接口地址、最早能取到多久、每次条数上限（实测一次并写结果）
- noise_note：一两句事实，比如「近 30 条上币公告里 22 条是股票永续」，不写评价
- confidence：每个字段的证据等级（官方 / 实测 / 二手）

== 任务 X7：上所路径样本 → alpha/review/x7_listing_paths.json ==
抽样 30 个近 12 个月在币安现货上线的币（覆盖不同市值，不要全挑大币；列出你的选取方法）。对每个币查它在上面这些交易所的首次现货上线日期和时间（UTC，精确到分钟更好，只到天也行但要说明），
每个日期带官方公告链接；没上线写 "no"，查不到写 "U"。目的：看一个币通常先上哪类所、后上哪类所。只给事实，不下「谁领先谁跟随」的结论。
币的识别用「符号 + 合约地址 + 链」，只有符号时标 weak，不合并。
```
