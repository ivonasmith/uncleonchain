# 表达规范 · 给观点，不给指令（v1，2026-11-15）

大叔 11-15 定的方向，所有会话、所有板块写页面文案时都按这份来。和 `docs/SEO规范.md` 并列：SEO 管页面怎么被找到，这份管页面怎么说话。

## 0. 为什么

- 用户看不懂，不是因为我们没给建议，而是我们给了读数、没给翻译。「涨腿 / 跌腿」直观，是因为它说的是**现在处在什么阶段**，不是**你该干什么**。
- 系统里没检验过的判断不能当指令；没人能预测黑天鹅。KOL 的直白靠的是立场，我们的直白靠**状态 + 分母 + 公开战绩**。
- 观点归人，证据归站：大叔推特可以有立场、链回网站；网站只说状态、历史和战绩。

## 1. 三档说法

| 档 | 是什么 | 例子 | 网站 |
|---|---|---|---|
| **一 · 状态** | 现在是什么天气 | 「BTC 在跌腿第 23 天」「宏观逆风：实际利率急升，又碰上信用利差走阔」 | ✅ 每个板块第一句必须是它，越直白越好 |
| **二 · 条件 + 历史** | 这种天气过去通常怎样，带分母 | 「过去 31 次资金费率转负，之后 30 天上涨 23 次（74%）」 | ✅ 必须写出次数 / 分母和检验等级；没检验的标「假设级」 |
| **三 · 指令** | 替读者做决定 | 不追高、加仓、减仓、风险预算打七折、止损、止盈、抄底、不开新空、买某币 | ❌ 首屏、结论句、卡片、description、首页一律不出现 |

第三档的唯一例外：**方法论 / 口径页原样引用研究框架**时可以出现（如 `config/l1_rules.json` 逐条照抄的宏观总文档），但要标明「研究框架原文 · 作者自用规则，不是给读者的建议」，且不能被拼进结论句。

## 2. 禁用词（结论句、首屏、卡片、首页、description）

不追高 / 追高 · 加仓 / 减仓 / 调仓 · 仓位 / 仓位倍数 · 风险预算（照常 / 降一档 / 打七折 / ×0.7）· 止损 / 止盈 · 抄底 / 逃顶 · 不开新空 / 分批加 / 分批买 · 买入 / 卖出 / 建仓（核心选币的「建仓条件」是流程名，保留，但只说「条件齐备 / 未齐」）· 「可以 / 应该 / 建议 / 别」+ 动作。

改写方法：把「做什么」换成「现在是什么 + 过去怎样」。

| 原句（第三档） | 改成 |
|---|---|
| 宏观逆风，节奏上不追高，风险预算打七折 | 宏观逆风（实际利率急升，又碰上信用利差走阔） |
| 资金费率转负，空头拥挤：短期不追空 | 资金费率转负，空头拥挤（已验证：过去 31 次，之后 30 天上涨 74%） |
| 风险预算降一档，不加仓 | 实际利率一个季度内急升，单独看也是一股逆风 |
| 不据此抄底 | 熊市里这条信号偏弱（历史 8 次只有一半上涨） |

## 3. 大白话

- 第一句不出现行话；行话往下放或进 ⓘ / `.term` 悬停。
- 用「涨腿第 N 天」「比 N 条里的 M 条走得久」这种说法，不用 P90、z 值、σ 打头。
- 每个读数旁边能回答「这算高还是低」：和历史比、和同类比，给分母。

| 行话 | 大白话 |
|---|---|
| L1 净流动性闸门触发 | 市场上的钱在变少、美元在走强 |
| 实际利率 13 周 +0.4pp | 扣掉通胀后的利率，一个季度涨了 0.4 个百分点（涨得快） |
| STH 成本 +1σ 压力区 | 最近 5 个月买入的人的平均成本再往上一档，过去常在这里卡住 |
| P90 | 十次里有九次没走到这么远 |
| 乐观度 z < 0 | 市场情绪比过去一年的平均水平低 |

## 4. 战绩（让观点可以被检验）

- 结论句写入即冻结（日志已经是），**30 / 90 天后自动对账**：当时说什么、之后 BTC / 篮子怎么走，对的错的都摆出来。
- 只有「已验证」规则能进结论句；「假设级」只在下面的分段里出现，并写明作废条件。
- 战绩页上线前，结论句只用第一档 + 已有回放统计的第二档。
