数据范围说明
  • 注册量来自完整 Agent ID 注册表；它不等于币安 Agentic Wallet 总量。
  • 交易地址 = 当日实际买卖的独立地址，不含仅铸造或领取的地址；同一地址同日多笔只算一次。
  • 成交额 = 已核平台内盘（曲线）买卖金额，按含手续费的毛额、只算 BNB 计价的币，不含二级 DEX；新发币 = 已核平台当日创建的 Agent 币；毕业 = 当日从内盘迁到 DEX。
  • 各平台怎么认 Agent 币：Gang 全平台合约强制 Agent ID 门禁；Flap 只算发币时设了 Binance Agent ID 门禁的币；Four.meme 只算合约标记为 Agent 钱包创建的币（买卖不限 ID）；AgentPad 为已核工厂。
  • 所有日期为 UTC 日；U 表示没取得完整数据，图上断开；0 表示完整读取后确实为 0。
