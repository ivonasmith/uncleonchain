3 · 识别价值来源一 / 二.3–二.5

按实际付款行为分，不按宣传赛道；混合来源列份额和未知部分

交易与投机基础设施

为什么有人付费 降低交易摩擦，提供流动性、借贷、抵押、杠杆、发行与风险转移

重点观察 去刷量交易、真实费用、用户留存、补贴依赖、市场成交敏感度

不能推出 有交易需求不等于收入稳定，也不等于代币享有收益

现实摩擦解决

为什么有人付费 跨境付款、工资、结算、资产获取等更便宜或更方便

重点观察 相对替代方案的总成本、到账 / 结算体验、复购客户、收入与兑付

不能推出 RWA 标签不证明权利有效；稳定币转账额不全是商业支付

新兴需求服务

为什么有人付费 AI Agent 等新用户为结算、权限、计算、数据或服务持续付费

重点观察 无补贴付费调用、重复客户、服务交付、净收入和替代成本

不能推出 机器人调用或钱包数量增长不证明真实付费需求

底层资源与安全服务

为什么有人付费 使用区块空间、数据、跨链通信、预言机、存储或安全服务

重点观察 谁购买哪项资源、单位价格、外部付款、供给成本和服务风险

不能推出 上层活动增加不保证收费或代币所得增加；安全奖励可能主要来自增发

收藏 / 娱乐 / 文化消费（框架补充）

为什么有人付费 收藏、游戏、社交身份等消费需求

重点观察 去掉奖励后的留存、真实消费、二级成交

不能推出 娱乐消费是需求，但不能描述为外部生产收入（五.1）

资产权利（买到什么）

主类型 + 次类型并存，写明当前主要价格驱动及证据；事实变化另建快照

货币与共识储备

优先核对 供给可信度、安全与结算属性、接受范围、持有和抵押需求

比较方式 宏观与资产自身供需，不强套市销率；比特币为首要观察基准

底层资源与安全资产

优先核对 使用是否必须购买 / 占用本币，费用归属、抵押要求、罚没与净发行

比较方式 真实资源需求、所需持有存量、可替代性和稀释；不能只按链上交易额估值

经营收益捕获代币

优先核对 已执行分配 / 回购、权利和更改约束、股权与代币分账

比较方式 与同口径可持续持有人所得及供给压力比较

资产支持或兑付凭证

优先核对 对底层资产的具体索取权、储备、托管、费用、兑付对象与条件

比较方式 兑付 / 净资产价值、信用与流动性风险；不套平台收入倍数

治理或未来权利预期

优先核对 当前能做什么、未来捕获要经历哪些决定和部署

比较方式 当前权利与未来情景分开，不把潜在开关当已到账收入

叙事、注意力或反身性主导

优先核对 信息扩散、参与动机、可识别资金、供给、退出与规则

比较方式 事件和交易情景，不以协议收入装饰价格合理性

暂无代币

优先核对 研究参与资格、贡献记录或未来产品机会

比较方式 不虚构代币估值；未确定发行的奖励不按确定收入计

产品有用但代币不捕获

已证实没有相应权利

停止用平台收入给代币做现金流估值；业务仍可研究，代币交易需要另有可证伪的叙事 / 事件 / 未来权利假设

权利或执行情况未知

转待核验；不因暂时没查到收入判为零，也不以「未来可能分配」通过门槛

早期产品尚无收入，但有可验证实现与参与窗口

保留前瞻观察，写清商业验证期限、失败条件和预算；不赋予成熟现金流估值

已证实有相应权利并执行

按经营捕获估值，核对资金来源、净稀释

机会类型（收益来源）

三类可以重叠，但不能在结果出来后更换解释

初始参与与生产

收益来源 公开分配、挖矿、资源贡献、早期使用、创作与提供流动性

必须验证 当前角色获得的份额能否覆盖全成本；优势会被竞争多快稀释

产品与资产重估

收益来源 真实使用增长、收入兑现、供给改善、估值修复

必须验证 业务增长如何传给所研究资产；市场遗漏了哪条可验证信息

叙事与事件交易

收益来源 新的注意力、新增买家、社区组织、上市与催化

必须验证 需求是否持续，事件已交易到什么程度，能否按计划退出

可证伪路径（至少写出一条）

真实经营与本角色捕获货币 / 资源需求公开初始参与优势具体叙事催化反身性资金窗口注意力转化

几条都没有可核查依据、只剩泛化愿景 / 口号 / 涨价截图的，不进重点研究，只留原始线索和重开条件

资金参与方式

有资金参与方式的进「可投资机会」，没有的进「预警观察」（新东西先盯着，之后可能开放参与）

二级买入代币质押 / 提供流动性存入资金赚积分 / 空投预期交易或使用产品赚积分 / 返佣公开发售 / ICO挖矿 / 资源贡献暂无资金参与方式

四个问题（缺一项先确定下一步查什么，不能用总分弥补）

机制变化

有什么正在发生的变化？

新资产标准、生产方式、资源贡献机制、产品需求、用户组织或分配规则；只换名字 / 热门词不算

市场预期差

为什么还没被价格充分反映？

信息未传播、机制难懂、流程复杂、市场误解价值归属、增长刚出现；「市值小」「没人讨论」不算

价值归属

研究的参与者能得到什么？

价值可能归开发者、平台、验证者、创作者、LP 或用户，不一定归代币持有人

可执行收益

收益能否兑现？

经过成本、竞争、锁定、流动性和退出检验；不能卖出的高报价不等于净值

5 · 三个门槛（不能由高分抵消）四.2

已确认危险、尚未核验和暂未发现风险是三种状态；开源 / 审计 / 放弃所有权 / LP 锁定只是部分证据

安全门槛

· 谁能升级、增发、暂停、改税、冻结或限制转移

· 谁控制 LP、金库和关键外部合约

· 是否有已验证的恶意行为、欺诈或无法卖出

· 反身性结构不等于欺诈，但同受安全门槛约束

关键控制权未知 → 停留待核验

数据门槛

· 身份（链 / 合约 / 池）一致

· 供给口径一致

· 价格方向（base / quote）正确

· 时点与历史窗口一致

链 / 币 / 池错了直接停止对应结论；供给或历史起点未知时估值和回测不能假装精确

执行门槛

· 指定金额能否买入并退出

· 手续费、税费、滑点、Gas、路由、锁定、失败成本列全

· 有卖出报价，不只看 TVL

6 · 形成判断五 / 七 / 八–十 / 十一.1 / 四.1

需求：谁在为何付钱

去掉奖励和上涨预期后，产品或行为还有没有吸引力？客户购买 / 娱乐消费 / 收藏 / 交易费 / 为补贴反复交互分别统计

必要性：为什么需要这种设计

和最接近的替代方案比：解决了什么？为什么上链、为什么这条链、为什么要独立代币？用户能感知的改善是哪一项

增长：数量增长还是价值增长

有效参与者、付费、使用频率、留存、重复收入、获客来源；按批次看留存，分母含离开者

价值归属：繁荣如何传给研究对象

使用行为 → 付款 → 供应方 / 协议收入 → 成本与激励 → 分配规则 → 本角色实际所得；提案回购 ≠ 执行回购

供给：新增买家要接住谁的卖盘

流通口径、解锁、排放、团队与早期库存、做市库存、LP 与跨链筹码；同一时间窗估算净新增供给 vs 自然需求

预期差与催化：为什么是现在

市场当前把它当成什么、我们哪条事实不同、什么事件让别人修正、要多久、什么情况承认错了

六句话判断（另写最强反方）

市场怎么理解它

当前主要定价逻辑及证据

我们有什么差异

一条尚未充分反映、可以验证的事实或机制

谁会继续买入 / 付费

用户、参与者或投资者，以及动机

谁可能卖出

排放、解锁、团队库存、早期参与者及其成本

什么会推动变化

具体催化、时间窗口与观察指标

什么会推翻判断

可观察事实、阈值或截止条件

找不到反方通常意味着研究还停留在宣传材料层面

估值指标必须服从资产权利 七.5

研究对象优先指标避免的误用
有可验证经营捕获的代币客户收入与留存、实际捕获比例、捕获相对估值、净发行及解锁用全部手续费代替持有人所得，或把协议收入当可分配净利润
交易基础设施去刷量费用、费率、交易份额、客户留存、补贴后收入把牛市爆量年化为常态收入，把激励交易当自然需求
支付 / RWA 服务客户重复使用、实际收费、兑付 / 托管风险与代币权利把资金过账、结算本金、储备收益全部归平台治理币
资源与安全资产单位资源收费、真实外部需求、强制持有 / 抵押、净发行与成本把经济活动规模直接等同链的「税收」，忽略降费竞争和奖励补贴
资产支持凭证可兑付净资产、费用、信用 / 清算与流动性对有锚定价值的凭证使用高增长代币市销率
共识或注意力主导资产供需、接受度、注意力转化和退出情景虚构现金流折现，或因没有收入就自动判零价值

· 市值 / 协议收入 与 市值 / 实际持有人捕获 分开，不混用「市销率」

· 捕获为零时没有捕获倍数，不写「0 倍很便宜」

· 流通市值、总量估值、最大供给估值单列

· 短期收入年化只是情景尺度，注明窗口

· 质押收益拆成客户费用 / 增发 / 补贴

· 销毁区分真实使用费用销毁与库存销毁，对照新增发行

· 非投机终端需求所贡献的收入占比，穿透不了保留未知

反身性 / 庞氏思维模型（经济模型标签，不是欺诈认定）

奖励吸引参与 → 买入或锁定提高币价 / 稀缺性 → 账面收益与抵押能力上升 → 更多资金和参与者进入 → 奖励兑现与解锁带来卖压

核心比较：新增资金及其加速度，能否承接存量兑现、增发解锁与杠杆退潮

新增需求

观测 去内部循环后的新资金、新付费 / 入金主体、复投与外部新增占比

转折 流入仍为正但连续减速；新增主要来自存量复投

奖励来源

观测 外部客户付款、协议收费、补贴、代币增发、后续参与者支出分别占多少

转折 收入未增长，收益率主要由币价和新增排放撑住

存量兑现

观测 已产生未领取 / 卖出的奖励、可退出本金、解锁日历与回本批次

转折 一批参与者同时达到可卖出或回本节点；新增资金不足以吸收

杠杆循环

观测 抵押品来源、借款用途、循环质押、清算位与同类资产相关性

转折 价格下跌引发被动卖出，且抵押品与收益来源同步恶化

退出容量

观测 指定金额的卖出报价、价格冲击、排队 / 锁定、真实对手方

转折 报价恶化、退出延时、深度集中，早于最后成交价明显变化

压力情景：不再有新增主体但存量仍复投 / 复投比例下降 / 价格下跌同时到期 / 解锁增加

社区证据（社区 / 混合属性适用） 八

· 独立梗源、原创传播、不同成员之间真实回复、独立贡献、建设交付、冷却期持续性

· 记录观察窗口、可见范围、去模板 / 机器人后的有效作者与回复者、头部发言占比

· 社交增长同源、同口径、同间隔比较；第一天只有基线

· 注意力链条：讨论增加 → 新主体参与 → 成交承接 → 退出深度

交易所事件 九

· 公告时间、修订时间、计划开盘、首笔实际成交、现货 / 永续、交易对和报价币分别记录

· 「首发」「扩散」只在已观测交易所集合内成立

· 比较事件前涨幅、首笔冲高、稳定开盘后表现、成交额持续性；窗口成熟后再算

· 交易所优先级只决定关注预算，不进质量分

环境与供需 十

· 新增买盘从哪里来

· 同类供给是否密集增加

· 退出对手方是否在收缩

· 同时报告绝对收益、相对 BTC、相对相关公链 / 赛道

· 环境好不能豁免合约风险

下一步 核对身份、来源和时间

待核验

下一步 指定缺口，以及哪项核查能改变结论

进入 对象明确，有可证伪假设，尚无已证实否决项

下一步 催化、反方、证伪条件与复查时间

优先研究

下一步 补机制、风险、供给与执行证据

执行评估

8 · 用结果检验方法十三 / 附录三 / 十五

· 分别评价发现（覆盖、延迟、身份确定率、独有线索、漏失）、判断（相对同来源同阶段是否改善）、执行（成交率、无法退出比例、扣成本收益）

历史量级对照：什么级别的创新 / 问题，对应什么量级的结果 十五（大叔 11-14 补充）

做预期管理：一个新项目按框架打分后，找出维度最接近的历史案例，看它们后来走到了什么量级。是历史对照，不是预测。

估值量级：峰值完全稀释估值（峰值收盘价 × 最大 / 总供给）；Coin Metrics 有流通市值的另列流通市值峰值

涨幅：峰值收盘 ÷ 首个可交易日收盘（P0 = 数据源首个可交易日，不是创世或可参与日）；另算相对 BTC 峰值倍数 max[(P/P0)/(BTC/BTC0)]（附录二 C）

资金量级：峰值 TVL（DefiLlama）、峰值 30 天手续费；募资 / 预售额要有来源，没有就 U

传播范围：峰值用户 / 地址 / 持有人，必须带来源和口径；没有就 U（第一版全部待补）

持续时间：P0 到峰值天数；收盘 ≥ 2 × P0 的天数；峰后跌回 P0 以下用了多少天；手续费 30 天均值 ≥ 峰值一半的天数

怎么找相似案例：按 需求来源、资产权利、机会类型（类别一致加分）+ M / E / V / D（0–4 差值）找最近的历史案例；未知维度不参与；结果给区间（最低–中位–最高）和样本数

  • 历史案例几乎都是「后来成功」的项目：有幸存者偏差，结果区间偏高；同期同类失败者正在补（对照组）
  • 案例分数是事后回溯打的，有后见之明偏差；第一版由 Claude 打，Codex 盲评后对比
  • 样本少（二十几个），区间只描述历史，不是概率，不是目标价
  • P0 是数据源首个可交易日：空投 / 挖矿 / 预售的真实参与成本更早更低，倍数不等于参与者收益
