Methodology

口径与规则

解读日志里的每一个判断都来自下面这些公开规则。规则改动会在更正记录里留痕，历史日志不跟着改。

层结论怎么来

L1 流动性：核心指标（稳定币 30 日增速、实际利率 20 日变化、广义美元 20 日变化、期货升水）各打 −1~+2 分，合计 ≥2 扩张、≤−2 收缩，其余中性。利差只做衰退信号提示，不计分。

L2 周期：以 MVRV Z-Score 所在区间为周期位置（缺失时退回 MVRV）。NUPL、Realized Price 与 MVRV 同源，只展示不重复计分。

L3 筹码：以交易所 BTC 7 日净流量为准：净流出 = 筹码离开交易所，净流入 = 留意抛压。框架里的 URPD / STH 系列暂无免费源，明示待接入。

L4 情绪：恐慌贪婪（−2~+2）、资金费率（−1~+2）、未平仓 7 日变化（−1~+1）合计 ≥3 过热、1~2 偏热、≤−2 偏冷，其余中性。

异动预警阈值

核心指标区间切换 · USDT+USDC 单日净增发 / 赎回 ≥ $1B · 交易所单日 BTC 净流量 ≥ 5,000 枚 · 资金费率正负翻转 · 10Y 实际利率单日变动 ≥ 10bp · Pi Cycle Top 触发 · 发射台赛道单日 ±25% · 发射台当日第一易主 · 深度追踪平台日环比超 ±60%。

宏观四层 · 指标与区间

L1 · 宏观流动性（水多不多？）

指标级别怎么读区间规则
USDT+USDC 总市值
DefiLlama		核心 · 计分稳定币是场外资金进场的通道。看 30 日增速：扩张 = 有新钱在进，收缩 = 在撤。按30 日增速：< -1% → 收缩；-1% ~ +1% → 持平；+1% ~ +3% → 扩张；> +3% → 强扩张
10Y 美债实际利率
FRED · DFII10		核心 · 计分持有无息资产的机会成本。下行 = 对 BTC 这类资产更友好，上行 = 压制。按20 日变化：20 日 ≤ -15bp → 下行；±15bp → 横盘；≥ +15bp → 上行
2Y / 10Y 利差
FRED · T10Y2Y		核心 · 不计分衰退与流动性拐点信号。历史上衰退多发生在倒挂「解除」之后，不是倒挂当下。不计入层打分。按水平：< 0 → 倒挂；0 ~ 0.5% → 偏平（刚解除倒挂）；> 0.5% → 正常陡峭
广义美元指数
FRED · DTWEXBGS		核心 · 计分覆盖 DXY 盲区的贸易加权美元。美元走弱 = 全球美元流动性宽松。（DXY 本身没有免费官方接口，用它替代）按20 日变化：20 日 ≤ -1% → 走弱；±1% → 横盘；≥ +1% → 走强
BTC 期货年化升水
Deribit（约 3 个月期）		核心 · 计分机构加杠杆做多的意愿。CME Basis 没有免费接口，用 Deribit 约 3 个月期交割合约替代，同一口径。按年化升水：< 3% → 冷淡；3% ~ 8% → 正常；8% ~ 15% → 偏高；> 15% → 过热
美联储资产负债表
FRED · WALCL		辅助 · 不计分QT / QE 节奏。阶段性参考，不计入层打分。按30 日变化：30 日 < -0.5% → 缩表；±0.5% → 持平；> +0.5% → 扩表
隔夜逆回购 RRP
FRED · RRPONTSYD		辅助 · 不计分流动性「蓄水池」剩多少。抽干后 QT 直接抽银行准备金。阶段性参考，不计入层打分。按余额：< $100B → 基本抽干；$100B ~ $500B → 低位；> $500B → 充裕

L2 · 周期定位（现在贵不贵？）

指标级别怎么读区间规则
MVRV
CoinMetrics		核心 · 计分市值 / 已实现市值 = 全网平均浮盈倍数。按水平：< 1.0 → 低估·历史底部区；1.0 ~ 1.5 → 偏低；1.5 ~ 2.4 → 合理；2.4 ~ 3.2 → 偏热；> 3.2 → 过热·历史顶部区
MVRV Z-Score
CoinMetrics（自算）		核心 · 计分（市值 − 已实现市值）÷ 市值历史标准差，把 MVRV 标准化到跨周期可比。按水平：< 0 → 底部区；0 ~ 1.5 → 偏低；1.5 ~ 3 → 合理；3 ~ 5 → 偏热；> 5 → 过热·顶部区
Realized Price
CoinMetrics（自算）		核心 · 不计分全网持币成本均价（价格 ÷ MVRV）。现价跌破它 = 全网平均浮亏，历史上是大底区。待证伪观察中。按现价溢价：现价 < 成本 → 跌破成本线；溢价 0 ~ 30% → 贴近成本线；30% ~ 140% → 合理溢价；> 140% → 高溢价
NUPL
CoinMetrics（自算）		核心 · 不计分净未实现盈亏 = 1 − 1/MVRV，和 MVRV 高度相关，看情绪阶段用，不重复计分。按水平：< 0 → 投降；0 ~ 0.25 → 希望 / 恐惧；0.25 ~ 0.5 → 乐观 / 焦虑；0.5 ~ 0.75 → 信念 / 否认；> 0.75 → 狂热
Mayer Multiple
CoinMetrics（自算）		辅助 · 不计分价格 ÷ 200 日均线。按水平：< 0.8 → 深度低估；0.8 ~ 1.0 → 低于 200 日线；1.0 ~ 1.5 → 合理；1.5 ~ 2.4 → 偏热；> 2.4 → 过热
Puell Multiple
CoinMetrics（自算）		辅助 · 不计分矿工日发行收入 ÷ 365 日均值，矿工视角的周期位置。按水平：< 0.5 → 矿工投降区；0.5 ~ 1.0 → 偏低；1.0 ~ 2.0 → 合理；2.0 ~ 3.5 → 偏热；> 3.5 → 过热
Pi Cycle Top
CoinMetrics（自算）		辅助 · 不计分111 日均线 ÷（2 × 350 日均线），≥ 1 即历史顶部信号触发。只用于顶部区警示。按比值：< 0.9 → 远离顶部信号；0.9 ~ 1.0 → 接近；≥ 1.0 → 已触发

L3 · 筹码结构（谁在进出交易所？）

指标级别怎么读区间规则
交易所 BTC 净流量
CoinMetrics（flash 口径）		核心 · 计分流入 − 流出。持续净流出 = 筹码离开交易所（提币囤币），净流入 = 潜在抛压。flash 数据次日可能小幅修订。按7 日合计：7 日 < -10,000 → 大幅净流出；-10,000 ~ -2,000 → 净流出；±2,000 → 进出均衡；2,000 ~ 10,000 → 净流入；> 10,000 → 大幅净流入
交易所 BTC 余额
CoinMetrics		辅助 · 不计分交易所托管的 BTC 总量。免费档更新有约 2 周滞后，只看趋势。按30 日变化：30 日 < -1% → 下降；±1% → 持平；> +1% → 上升

L4 · 情绪衍生品（短期会不会超调？）

指标级别怎么读区间规则
恐慌贪婪指数
alternative.me		核心 · 计分综合波动、成交、社媒、搜索的情绪温度计。按水平：0 ~ 24 → 极度恐慌；25 ~ 44 → 恐慌；45 ~ 55 → 中性；56 ~ 75 → 贪婪；76 ~ 100 → 极度贪婪
BTC 永续资金费率
Hyperliquid（日均年化）		核心 · 计分多空谁在付钱。含约 11% 年化的基准利息（和币安 0.01%/8h 同量级），所以「正常」不是 0。按年化：< -5% → 空头拥挤；-5% ~ 5% → 偏冷；5% ~ 20% → 正常；20% ~ 40% → 多头偏热；> 40% → 多头极度拥挤
BTC 未平仓合约
Hyperliquid		核心 · 计分链上最大永续所的 BTC 未平仓名义价值，看 7 日变化判断杠杆在堆还是在出清。单一交易所口径。按7 日变化：7 日 < -15% → 去杠杆；±15% → 平稳；> +15% → 杠杆快速堆积
山寨季指数（自建）
CoinGecko（自算）		核心 · 计分市值前 50（剔除稳定币、包装币、质押衍生品）里 30 日涨幅跑赢 BTC 的占比。blockchaincenter 原版用 90 日，没有免费接口，这里是自建口径。按占比：< 25% → 比特币季；25% ~ 50% → 比特币偏强；50% ~ 75% → 山寨偏强；> 75% → 山寨季
BTC 市值占比
CoinGecko		辅助 · 不计分和山寨季指数交叉验证。按水平：— → 只看趋势

解读日志规则

日志日期 = 解读当天（UTC），每个读数带自己的数据日期（FRED 按美国工作日、交易所余额约有 2 周滞后，超过容忍天数标 ⚠）。 写入即冻结；同一天重跑且核心缺失变少才覆盖一次并标「补录」。周复盘按 ISO 周（周一至周日），月复盘按自然月。人工点评放在 content/journal/，单独标注。

发射台口径

统计口径发射台一律用手续费（fees），不用成交量；成交量口径覆盖不全，会系统性低估份额。
统计周期只报「昨天」这一个 UTC 完整日；当天数据永远不完整，不进正文。
发射台矩阵DefiLlama Launchpad 类目全部协议；多链协议的分链数字用 DefiLlama 分链拆分；30 日走势来自本站逐日台账。
赛道份额深度追踪平台的份额分母是 Top60 当日总量（和文字解读一致）；矩阵页的份额分母是全类目。
延迟处理某个数据源没出昨天的数，标「延迟」，不拿旧值顶替、不记 0。
Flap / StonkFunFlap 是税代币模型、StonkFun 的 fees 只记平台自己那份，跨平台比较用协议收入。
PONS 销毁转到 0x…dEaD 地址，不是调用 burn()，市值一律按 burn-adjusted 流通计。
绝不做的事不拿历史峰值和现在比来判断一个平台是否「死了」；只给数据，不给买卖建议。
