# RWA 研究方法框架

> 网站版，2026-11-14。来源：大叔与 Codex 讨论确认的《rwa-framework-v1》和 11-14 交接说明，由 Claude 整理。框架「讨论过」不等于里面的具体事实「核实过」：事实一律以页面上带日期和来源的读数为准。只给数据和过程记录，不是买卖建议。

## 1. 看什么

全产业链：发行、基金与国债、股票、商品、信贷、房地产、收藏品、交易聚合、抵押借贷、结算托管、身份合规、数据预言机，以及相邻的衍生品。小产品、早期产品、没发币的平台都留位置，不只看大市值代币。

## 2. 三条独立的逻辑

同一个项目可以同时落在几条线上，分开记、分开判断：

- **业务与价值捕获**：有没有真实的付费方；收入最后归谁（公司、基金管理人、DAO、代币持有人）。
- **事件与叙事**：上新、监管、机构合作、指数纳入这类有日期的事件。现金流权利还不清楚时，也可以只登记事件。
- **早期参与**：产品使用、积分、测试网、流动性服务。积分不等于会有空投。

## 3. 四个问题

每条业务链路都问：**谁付费、谁收钱、谁承担成本、谁有权拿到收益**。

页面「谁在收钱」一节按这个口径拆：手续费（用户付的总额）→ 协议收入（协议自己留下的）→ 持有人收入（分给代币持有人的）。三个数差得很远是常态，不能拿手续费当代币价值。

## 4. 身份：每样东西单独登记

| 身份 | 是什么 | 常见混淆 |
|---|---|---|
| 资产币 | 一份基金、国债、黄金、股票的链上份额 | 被当成平台币（例：XAUt 是黄金份额，不是 Tether 的平台币） |
| 平台币 / 协议币 | 发行平台或协议自己的代币 | 平台币涨跌和底层资产规模不一定有关 |
| 原生币 | RWA 专用链的 gas 币 | 和链上资产的规模不是一回事 |
| 公司股权 / 上市股票 | 发行公司本身 | 链上看不到，收入归股东 |
| 稳定币 / 生息美元 | 美元负债，部分把国债利息转给持有人 | 和国债基金份额口径重叠 |
| NFT / 收藏卡凭证 | 线下实物的提货或所有权凭证 | 链上记录不等于线下实物已核实 |
| 积分 | 活动记录 | 不能自动推导空投 |

平台币状态只有四种：**已发平台币 / 明确声明不发 / 未确认 / 传统机构产品（无平台币可言）**。没查到 ≠ 没有：未确认不能补成「无币」，资产币不能填作平台币。

去重按实体、官网域名、产品、合约（链 + 地址）；**symbol 只作提示**——同一个 symbol 在不同链上可能是不同的东西。合约要标角色：平台币合约、资产币合约、业务合约、DEX 池子、CEX 交易对分别显示。

## 5. 口径

- AUM、TVL、市值、净申赎、跨链桥接、价格、成交额、手续费、协议收入、持有人收入，各按自己的口径记，**不混加**。
- 嵌套资产不重复求和：黄金在「商品」里，货币基金和「国债」大量重叠，生息美元底层也是国债。
- 每日采样的钟点不同时，相邻两次之差写「两次采样之间」，不叫「24 小时变化」。
- 缺测就留空，不用 0、不用估算补。

## 6. 证据分级

| 证据 | 能证明 | 不能证明 |
|---|---|---|
| 官方材料 | 项目怎么披露、规则怎么写 | 披露是否真实 |
| 链上交易 | 某个动作发生过 | 线下资产存在、法律上有索取权 |
| 储备证明 / 审计 | 某个时点、某个范围的余额 | 时点之外、范围之外的情况 |
| 数据平台 | 平台按自己口径的统计 | 口径之外的覆盖；也不等于有转载许可 |

政策分清：表态、咨询、通过、生效、试点、许可。

## 7. 判断怎么写

研究标的的每条判断要有：**当前状态、理由、触发条件、失效条件、参与条件（资格 / 地区 / 门槛）、参与成本、退出路径、最后复核时间**。

状态只用这几档：

| 状态 | 意思 |
|---|---|
| 待重核 | 历史判断，还没按原始来源重新核对，不当当前结论 |
| 观察 | 机制值得跟，证据不够 |
| 等待证据 | 明确知道缺哪条证据，等它出现 |
| 条件齐备 | 列出的触发条件都已出现（不等于建议参与） |
| 已失效 | 失效条件已出现 |
| 历史 | 窗口已过，只留档 |

允许明确写「等待证据」。新判断追加版本，旧版本不删不改；最后复核超过 14 天的，页面标「过期待复核」。

## 8. 分层

轻量发现（自动读数、发现队列）和深度研究（研究标的）分开。采用、收入、机制、政策、风险方面的证据推动升级；证据少但机制值得探索的产品也留少量名额。「6 项重点 + 2 项探索」是试行安排，不是固定配额。

## 9. 不做什么

- 不写买入、卖出、仓位、止损。
- 不公开大叔的持仓（利益披露方式待定）。
- 不把公开页面能看到的数据当成有转载许可：每个数据源的使用条款单独确认。
