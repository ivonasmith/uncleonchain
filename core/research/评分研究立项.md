# 核心选币评分研究 · 立项书（v0.2，2026-11-14）

状态：**进行中**（2026-11-14 大叔要求立即开始；当前阶段 M1–M2）。研究结束前，观测台不展示评分、不按分数排名；读数照常每天更新，评分仍在后台记录（样本外检验用）。

## 一、为什么立项

- 观测台原型给 6 个模块打 0–3 分（R 收入趋势、C 价值捕获、V 估值、D 价格×收入、B 业务量、S 供给），分数阈值是拍定的，没有检验过。
- 第一轮回测（2026-11-14，`core/score_backtest.py`）：38 个有协议收入的代币，2023-03 起每月一次，判定标准事先写死，**R / C / V / D 和合计分 0 / 5 通过**。
  R（收入趋势）和 V（估值）方向是对的但不显著，C、D 看不出区分能力，B、S 没有历史数据未检验。
- 结论：现在的评分不能拿来选币，也不能拿来排名。要先回答“哪些读数真的有用、怎么合成”，再上线评分。

## 二、要回答的问题

1. **单个读数**：下面每一项，单独看能不能区分之后 30 / 60 / 90 天相对山寨篮子（宏观页同一个篮子）的表现？
   - 基本面：协议收入增速（7v30、30v30、90v90）、持有人收入占比、市值 / 年化持有人收入、市值 / 年化收入、FDV / 收入、收入领先价格、业务量增速、日活增速、抽成率、国库（非自家代币部分 ÷ 市值）、核心开发者变化、30 天解锁占流通量。
   - 资金面：合并成交额排名及其变化、常客 / 新进榜 / 掉榜、合约占比、换手率。
   - 技术面：距 MA200、距 120 日高点、30 日区间位置（规则 R4 已证明“近期相对强弱”无效，这里只检验均线 / 回撤类）。
2. **合成**：通过的读数怎么合成（等权排名、按 IC 加权、简单回归），合成后样本外还剩多少？
3. **分阶段**：在 L2 不同周期阶段、BTC 涨腿 / 跌腿里结论是否不同（接本站 L2 状态机和涨跌腿）。
4. **和拉盘复盘对上**：事前读数能不能提前区分“龙头 / 后发跟涨 / 落后”（08-19 锚点那一期 + 历史上其他 BTC 急拉窗口）。
5. **建仓条件里没验证的三条**：R2（30 天解锁 ≥ 5%）、R3（价格跑在收入前面 > 30pp）、R6（渠道 B 平台收入回升）各自有没有用。

## 四、方法与判定标准（跑之前写死，跑完不改）

- 时点：每月 1 日，只用前一天及以前的数据。
- 样本切分：**2023-03 ～ 2025-06 用来找规则，2025-07 ～ 2026-10 只用来检验**（样本外）。
- 指标：月度 Spearman IC、分五档平均超额、IC>0 月份比例；60 / 90 天重叠样本用非重叠子样本或 Newey-West 修正。
- 控制：市值大小、近 30 天涨跌、板块（同板块同涨同跌）。
- **通过**：样本外 30 天 IC > 0 且 t ≥ 2，60 天同号，五档超额大体单调；
  **证伪**：样本外 IC < 0 且 t ≤ −1；其余记“未通过”。
- 合成评分只能用“通过”的读数，合成后也要在样本外单独过一遍同样的标准。
