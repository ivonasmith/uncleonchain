# 核心选币 · 选币规则 v1（草案，2026-11-14 与大叔逐条确认）

替代原型里人工指定的“埋伏仓候选”。名单 = 规则每天跑出来的结果，冻结记录、事后和山寨篮子对账；错了改规则，不改名单。
评分研究（M2 / M3 / M3b）结论：公开读数做“预测排名”没有通过检验，所以本规则用**分类 + 流动性 + 事实门槛**，不打分。

## 一、入场门槛（所有类型共用）

1. 在币安上市（现货有交易对）。
2. 流动性：近 90 天合并成交额（币安现货全部交易对 + U 本位 + 币本位合约）排名的**中位数 ≤ 100**。
3. 例外：原观测池里有收入的币（UNI、HYPE、CAKE、AAVE、PUMP、SKY、RAY、JUP、ETHFI、MORPHO、ENA、NEAR，及 PENDLE、LDO、AERO、GMX）不受第 2 条限制，排名靠后的标“流动性不足”。

## 二、五大类（决定看什么）+ 子类（每个子类按流动性取前 3）

| 大类 | 子类 | 怎么判 | 取几个 | 看什么 |
|---|---|---|---|---|
| 共识储备型 | — | 美国有已上市交易的现货 ETF，且协议收入相对市值很小（核查表 `美国现货ETF核查_20261114_codex.md`） | **全列** | 宏观流动性、ETF 净流入、长期持有者占比（宏观页 L1–L3） |
| 主流公链型 | — | 主流 L1 / L2 原生币，没有美国现货 ETF | 前 3 | 链上活跃、费用、生态资金 |
| 现金流有用型 | 交易所和 DEX / 借贷与抵押 / 衍生品 / 发射台 / 现实摩擦解决 / AI 新兴需求 / 卖水人过路费 | DefiLlama 有真实协议收入；子类按协议类别映射 + 人工复核 | 每个子类前 3，**另加原观测池全部** | 收入增速、价值捕获状态、收支剪刀差、护城河 |
| 博弈控盘型 | 叙事 / 反身性（挖矿、质押、节点、积分）/ 筹码控盘 | 没有可核实的价值捕获，价格靠叙事或反身性机制 | 每个子类前 3 | **机制拆解卡**（见第四节） |
| 注意力情绪型 | Meme | CoinGecko meme 类目 + 人工复核 | 前 3 | 讨论度（待接入）、持币分散度、池子流动性 |

- 有 ETF 但有真实收入的（LINK、TRX、NEAR）放现金流有用型，加“ETF”标签。
- 大类按**价格的真实驱动力**判；叙事、赛道只做标签（例：TAO = 博弈控盘型·反身性，标签 AI 叙事、挖矿排放）。
- 都不沾的中间态不观测。
- 目标规模 30～50 个。

## 三、现金流有用型的状态标签（标注，不剔除）

- 价值捕获：已执行（回购销毁 / 回购持有 / 直接销毁 / 分红 / 储备，分开标）· 承诺未执行（例：LDO 自动回购未触发、MORPHO / ENA 费用开关未开）· 暂停中（例：AAVE 2026-04-19 起）· 无。
- 收支剪刀差：过去 12 个月回购 + 销毁金额 vs 未来 12 个月解锁 + 增发金额。
- 护城河：份额趋势、去掉补贴后的收入留存 + 人工判断（依据存 Notion）。
- 每条状态都要有证据：地址（DefiLlama 适配器 + 官方公布）、链上核对、官方出处。

## 四、机制拆解卡（博弈控盘型，从 TAO、WLD 开始）

| 拆什么 | 读数 |
|---|---|
| 真正能卖的有多少 | 总量 / 质押或锁仓 / 未解锁 / 自由流通 |
| 排放 vs 真实收入 | 每日新增供给（美元）vs 真实付费收入 |
| 是不是合约在带价格 | 合约成交占比、合约持仓 ÷ 市值、资金费率、期现价差 |
| 筹码在谁手里 | 前 N 大地址占比、交易所余额变化 |
| 价格和基本面是否背离 | 币价 vs 使用量 / 收入走势 |

## 五、数据存放

- 自动取数的每日数字（供给、销毁、回购、名单冻结记录）→ 仓库 `data/core/`。
- 人工核对的证据（机制、地址、解锁日历、分类依据、ETF 表）→ Notion《核心标的基本面与叙事追踪》页下的数据库（备份用）+ 仓库同步一份。
