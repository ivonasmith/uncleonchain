## 2. 回测怎么做的（判定标准在跑之前写死）

- 样本：DefiLlama 有协议收入、币安有 USDT 现货、近一年收入 ≥ 300 万美元的代币，按母协议合并；
  身份核对：母协议 gecko_id + CoinGecko 现价对币安收盘差 ≤ 5%，否则当同名不同币剔除（剔除名单在结果文件 `dropped`）。
- 时点：2023-03 起每月 1 日，只用前一天及以前的数据（收入截至前一天，价格用前一天收盘）。V 要历史市值，CoinGecko 免费只给 365 天，所以只有近 11 个月。
- 结果：之后 30 / 60 / 90 天收益 − 同一时点全体样本中位数。
- 指标：每月 Spearman IC，取平均、t（均值 / 标准差 × √月数）、IC>0 的比例；高 1/3 减低 1/3；各分档平均超额。
- 判定：30 天、60 天 IC 都 > 0 且 30 天 t ≥ 2 → 已验证·方向；30 天 IC < 0 且 t ≤ −1 → 已证伪；其余 → 未通过。
