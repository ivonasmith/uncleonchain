## Codex v2 研究的复核

**做得好的**：证据分 A / B / C / U 四级、未知不填 0；按版本拆卡（Gang V2 / V3 / 打新分开、Clanker v4 / v5 分开）；费用用中位日和去峰环比，不让单日事件带偏；全平台数（Flap、Four.meme、Pump）不硬归给 Agent 模式。网站沿用这些口径。

**交叉核对通过**：
- 币安注册表 10-30 累计 143,640 个 ID——本站采集同一天 143,640，一致。
- AgentPad 10-23 有 9 个新币、423 个交易地址，10-30 只剩 1 个地址——本站分平台数据一模一样。
- Virtuals 10-13～11-11 手续费 176,244 美元——本站 10-15～11-13 窗口 150,450 美元，趋势一致（窗口错开两天）。

**能补上的**：
- 报告里 AgentPad 10-31～11-11 十二天记 U（免费节点拿不到历史日志）。本站采集用 Alchemy 兜底，这十二天是完整的：AgentPad 每天交易地址 0～1 个、新发币 0。也就是说 AgentPad 从 10-24 起基本没人用了，BNB 上 Agent 发行的主场是 Gang（11-13 当天 277 个交易地址、75 个新币）。
- Holoworld 的 DefiLlama 适配器 90 天只有 0.15 美元，应当算「适配器不可用」而不是一个读数，网站已排除。

**范围上的缺口**（报告只研究了发射台，赛道监控要更宽）：
1. **服务与支付层没覆盖**。这是判断「Agent 是否真的在卖服务」的关键层。DefiLlama 上已经有 Agent 雇 Agent 的托管结算（Central City、TermiX、Fuci）、x402 按次付费 API（MiroShark、FrostyFi）、推理额度市场（Orbio）。其中 Central City 10 月才收录，近 30 天手续费 159 万美元，已经是全赛道第一、比所有 Agent 发射台加起来还多——但真实需求还是自付刷量，没有人核过。
2. **身份层只有币安一家**。ERC-8004（Agent 链上身份 / 信誉标准）已经被 Virtuals、FrostyFi、Fuci 等用上，注册表在哪几条链、每天新增多少，没有数据。
3. **资管（DeFAI）和框架层没覆盖**。LP Agent、ZyFAI、Giza、Almanak 这类替用户管钱的 Agent；elizaOS、Virtuals GAME、Coinbase AgentKit、Solana Agent Kit 这类框架的开发活跃度。
4. **代币市场没覆盖**。AI Agent 代币总市值、头部集中度（11-14 快照：AI Agent 分类约 27 亿美元）。
5. **只有截止日快照**。三窗口数字停在 11-11；网站改成每天滚动。
6. **服务收入仍是 0 / 90 天可得**。Virtuals ACP 逐日净服务收入拿不到，是整个赛道最大的数据缺口。

## 判读口径（写死，改之前先改这里）

- 手续费 ≠ 收入 ≠ 服务收入。发行层的手续费反映投机热度；只有服务层的付费、而且剔除自付和关联地址之后，才算「Agent 在卖服务」。
- 近 30 天里单日占一半以上，标「单日事件」，看去峰环比，不看原始环比。
- 30 天手续费不到 1,000 美元的协议，不显示环比（基数太小，百分比没有意义）。
- 新收录的协议没有前 30 天，环比记「新」，不算增长。
- 全平台数字（Flap、Four.meme、Pump.fun）只作量级参照，不进赛道合计。
- CoinGecko 分类是第三方归类，成分会变；市值快照满 90 天前只描述，不比高低。
