# 交易所上币回报研究（立项）

立项日 2026-11-16 UTC。起因：大叔希望用「各家交易所上线一个币之后价格怎么走」来辅助判断，包括币到最高点的时间、各所上线的「背书」位置、整体回报和涨幅分布。

**本文先把口径和判定标准写死，数据跑出来之后不许改标准。** 改标准只能升版（写更新日志），已算出的历史读数不回改。

## 0. 红线（表达）

- 网站只摆「历史分布 + 样本数 + 检验等级」，不写「跟着买」「涨 X% 就卖」「止盈止损」这类指令（`docs/表达规范.md`）。
- 句式示例（允许）：「Binance 现货上线的 29 个币里，7 天内最高点的中位数是 +Y%，出现在第 Z 小时；有 M% 在 7 天后低于上线价。」
- 用户拿这些数据怎么用、是否结合其他信息做空，由用户自己判断，网站不替他下结论。
- 所有回报都是**事后读数**：参考价 = 第一根 1 分钟 K 线的开盘价，普通人基本成交不到，不是可执行价。

## 1. 样本

- 来源：`data/alpha/listings.json`（Binance、OKX；其它所接入后加入）。
- **现货和永续分开统计，永续不并进现货。** 现状：Binance 主事件 114 个，其中现货 29、永续 85；OKX 现货 15 个有窗口。
- 剔除：代币化股票 / ETF / TradFi（项目规则）、OKX 的 USD 交易对（OKX US，全球站无 K 线）。
- 入选条件：有完整 24 小时窗口（`w.complete = true`）。取不到 K 线的事件**不静默丢弃**，在每张表旁写「未取到 N 个」。
- 同一个币在同一所多次上线（现货 + 永续、不同报价币）：每个 市场 × 所 只取第一次，避免重复计数。

## 2. 指标定义（写死）

设 t0 = 该所该市场的第一根 1 分钟 K 线时刻，ref = 该根开盘价，H ∈ {24 小时, 7 天, 30 天}。

| 编号 | 指标 | 定义 |
|---|---|---|
| M1 | 最高点涨幅 | H 内最高价 / ref − 1。24 小时用已有分钟级读数（`high24`）；7 天、30 天用 1 小时 K 线的最高价 |
| M1t | 到最高点的时间 | 最高点所在时刻 − t0。24 小时精确到分钟，7 天 / 30 天精确到小时。并列取最早 |
| M2 | 终点回报 | t0 + H 那一根的收盘价 / ref − 1 |
| M2b | 30 分钟后起点的回报 | t0 + 30 分钟那一根的收盘价为起点，到 t0 + H 收盘价的回报 = (1 + M2) / (1 + 30 分钟回报) − 1。比 M2 更接近「看到上线之后才行动」的读数，仍是事后读数 |
| M3 | 综合回报 | 对 M2 取**中位数**为主口径；平均数只作旁注（被少数暴涨币拉高，如 OFC 24 小时 +81%）；另列「M2 < 0 的比例」 |
| M4 | 分布 | M1 与 M2 各列 P10 / P25 / P50 / P75 / P90，加区间计数：< −20%、−20%～0、0～20%、20%～50%、50%～100%、> 100% |
| M5 | 背书（跨所） | 同一个币在多家所的上线顺序；对每个后续上线记：距首次上线多少小时、当时价格相对首次上线参考价的涨幅、当时价格相对该币 H 内最高点的位置（当时价 / 最高点） |
| M6 | 前置涨幅 | 小所上线到大所上线之间的涨幅（只在两所都有价格序列的币上算） |
| M7 | 同期对照 | 每个窗口同时列 BTC 同期涨跌，并给「超额 = 币 − BTC」，否则牛市里什么都涨 |

## 3. 判定标准与检验等级

- **描述级**：n < 20 的格子（所 × 市场 × 窗口）只列数字，标「样本不足」，不写任何分档、不比大小。
- **检验级**：n ≥ 20，才允许说「分布偏哪边」。是否「领先 / 跟随」分类需要**至少 20 个跨所共同上线的币**，目前远不够（只有 Matrix（MTX）一个），一律写「待积累」，不硬分。
- 不合成综合分数，不给交易所排名。
- 币的识别：资产符号 + 合约地址 + 链全部一致才算同一个币（强匹配）；只有符号一致算候选，不进 M5 / M6 统计（聚类规则见 `alpha/review/x5_cluster_draft.md`）。

## 4. 已知偏差（写在页面上，不隐藏）

1. 事后读数：参考价不可成交，第一分钟的滑点和深度没有记录。
2. 幸存者：后来下架、改代码、迁移的币可能取不到 K 线，已列「未取到 N 个」。
3. 窗口重叠与单一行情：样本集中在少数几周时，结果反映的是那几周的市场，不是交易所本身。M7 的 BTC 对照用来看这一点。
4. 现货和永续是两种事件，不混。
5. 高点是事后选出来的最大值，M1 天然偏高；M2 才是持有到窗口末的结果，两个必须一起看。
6. **开盘尖峰**：第一分钟的最高价常常是瞬间的尖峰，不是可成交价。R0 实测币安现货 28 个里 14 个的最高点出现在第 0 分钟。所以 M1 / M1t 的读数必须同时列「最高点出现在开盘 5 分钟内的占比」，页面上标「含开盘尖峰」；更贴近实际的读数看 M2b。

## 6. 作废条件

- 任一 所 × 市场 × 窗口 的 n < 20：该格不出分布结论。
- 取不到 K 线的占比 > 20%：该格标「数据缺失过多」，不出结论。
- M7 显示样本期 BTC 同期涨幅占超额的大部分：页面第一句改成「读数主要反映该时期的市场」。
