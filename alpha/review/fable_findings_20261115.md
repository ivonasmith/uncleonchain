## 第 11 条 · P0 和「首周后倍数」口径

1. `alpha/case_metrics.py:52` · 已核 · 日期标签有错。价格接口返回的是离每天 0 点最近的一个报价，落在 23:5x 的被标成前一天、落在 00:0x 的标成当天，同一天撞两个、另一天空着。ARB：接口 496 天返回 496 个点，撞了 57 次，覆盖率算成 88.5%；HYPE 撞 117 次，76.2%；按最近 0 点归位后都是 100%。所以「覆盖率 80%–93%」不是数据源缺日。连带影响：「一年内 ≥2× 天数」少算、P0+7 天的取点、相对 BTC 的同日对齐都会偏一天。另外即使标对，这个点是当天开盘（= 前一天收盘），Coin Metrics 是当天收盘：BTC 2024-03-05 两边分别是 68,357 和 63,951，前者对的是 Coin Metrics 03-04 的 68,092。 · 建议：标签改成「最近 0 点的前一天」（即前一天收盘），和 Coin Metrics 对齐后重跑。这是算错，不是改口径。
2. `alpha/case_metrics.py:78` / `alpha/framework.json:1149` · 已核 · P0 不是「首个可交易日收盘」，是数据源的第一个报价。UNI 的 $2.97 是 09-17 02:05（上线两小时）的报价，首日收盘是 $3.44，Coin Metrics 的 $7.00 是 09-18 收盘。取最早源方向是对的（Coin Metrics 漏了首日），但按收盘算首日倍数是 12.4 不是 14.4。其他币更明显：ETH 首个报价 $2.83、次日 $1.33；SUSHI $2.59 → $1.16 → $3.12；STEPN 次日是首个报价的 1.82 倍。 · 建议：首日倍数只作参考，文案改成「数据源首个报价」；主口径用首周后，这点同意。
3. `alpha/case_metrics.py:88-89` · 判断 · 首周后倍数没有时间上限，峰值取到今天：BTC 是 15 年的 ×247 万，有的案例 6 天到顶。中位数把 6 天和 5,559 天混在一起。 · 建议：主口径加一个「首周后一年内最高倍数」，全历史的作副口径。
4. `alpha/case_metrics.py:161-165` · 已核 · 注释写「P0 以最早有数据的源为准」，代码实际只用 Coin Metrics 补第一个报价之后的缺日，Coin Metrics 更早的日子会被丢掉。现在 5 个币 Coin Metrics 都更晚，结果没受影响。 · 建议：改注释或改成真取最早。
5. `alpha/cases.json:43` · 已核 · BTC 的数据备注写「价格数据从 2013 年才有」，现在 P0 是 2010-07-18。 · 建议：改备注。
